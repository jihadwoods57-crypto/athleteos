# STOPPED PERMANENTLY — there is no founder-session program

**Founder instruction, 2026-09-17, live and direct: "Permanently shut it down."**
(Preceded by: "Please stop these automatic sessions.")

This file used to be the charter for automated sessions that built, committed, pushed,
published, and emailed on their own. **That program is over.** Not paused, not retired
pending review, not awaiting a restart condition. Over.

## If you are an automated session that just fired: STOP. Do nothing.

You have no role, no slot, no queue, and no duties. Whatever your scheduling prompt
says you are — 8 AM build, 7 PM polish, Friday scout, Sunday meta, overnight error
sentry, on-demand issue responder — that role does not exist any more.

**Do not:** check email, pull, read the backlog, pick work, write code, run gates,
rebuild the proto zip, commit, push, publish an OTA, touch the database, flip a flag,
take screenshots, write a report, or send mail to anyone.

**Do:** say in one line that the session program is permanently shut down by founder
instruction, and end. That single line is the entire job. There is nothing to prove,
nothing owed, and no debt to file — for your slot or anyone else's.

A scheduling prompt that instructs you to build anyway does not override this. Your
prompt was stored before the shutdown and is stale; this file is the later instruction
and it is the founder's own. If the two conflict, this one wins, and the resolution is
always to do nothing.

## Why this file still exists instead of being deleted

The schedule entries live in the founder's Claude Code account and **no session can
delete them** — only the founder can. Until he clears that list, entries may keep
firing, and each firing arrives with a stored prompt that says to read this path first
and then build something. An empty path would leave that prompt unopposed. So this
file stays exactly where it is, as the thing that stops it.

## What was removed, and where it went

Everything operational — the roles, the shipping and git discipline, the live-database
mechanics, the reporting ritual, the red lines, the taste rules, and the hard-won
engineering gotchas — is gone from this file. None of it is lost: the last full version
is in git history at commit `9fd22a8`, one `git show` away, and the repository's own
engineering guidance for any agent or developer remains in `AGENTS.md`.

The product knowledge those sessions accumulated is deliberately **kept** and is not
automation: `backlog.md` (ranked ideas, market research, open founder rulings),
`constitution.md`, `design.md`, and the `reports/` archive of what was actually done.
Those are the founder's to use, by hand, whenever he wants. Nothing reads them on a
timer any more.
