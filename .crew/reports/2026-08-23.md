## The week's grade: A- on the work, incomplete on the last mile

This was the setup week — the charter went in Saturday night and the first daily
sessions run today — so there are no daily sessions to grade yet. What there IS is a
week of shipping (about 37 commits, Aug 16–22), and it holds up well:

**High-value, real:** the health-connect screen stopped claiming a connection Apple
never confirms (that was a straight-up lie to any athlete who unchecked every box);
HealthKit got wired with the right module after the docs named one that could never
work; keyboard users can finally reach every knob the stylesheet always promised a
focus ring for; the day screen stopped hauling two months of meal data to paint today;
and the trust screen now shows the exact photo-day count the server checks, not a
client guess.

**The standout:** the adversarial-review rule earned its keep in its first real outing.
The review of the day-load split caught that the trust screen's "N of M photo days"
would have RUN BACKWARDS for long-tenured athletes the moment the window narrowed.
That's the exact class of quiet regression the rule exists for, and it was fixed before
the push, with a regression net. Keep that rule sacred.

**What was NOT proven:** nothing in the week's log claims an EAS publish or a live
manifest hash match. Zips are rebuilt and committed, gates are green — but by our own
rule 4, until the live manifest matches, users may still be running code from before
all of it. That's now backlog #1 for the first session with publish credentials.

**What the founder had to correct:** the charter itself, twice within an hour of
seeding — the error-watch design assumed webhooks the cloud can't mint. Today added a
third instance of the same disease: the reporting section assumed the Drive connector
can edit the ops doc, and it can't. Pattern named and now a standing gotcha: prove a
tool exists in-session before writing it into the charter.

**Staleness caught:** AGENTS.md said verify runs "nine gates"; it runs twelve. That's
the same file that once said v56 for the whole SDK 57 cycle. Fixed, and worded so the
next staleness is self-evident.

## What the charter now does differently

- Sunday META is a named role in the schedule, not just a constitution footnote.
- Six new gotchas from this week's burns: server-enforced numbers must come from server
  rows, not client proxies; optional `require` of native modules is load-bearing for
  OTA; prose docs lie — trust package.json and verify's own summary; entry-by-entry zip
  compare is the proof-of-scope standard; failed reads keep the last known value; and
  charter mechanisms must be proven in-session before they're written down.
- Reporting: the `.crew/reports/` fallback is now the acknowledged standing path until
  a Docs editor exists — no second doc, no copies.
- Backlog: old #4 marked done (it shipped Saturday); new #1 is proving the OTA actually
  carries the week's committed work; the em-dash count flagged stale (246 already
  removed); a fourth "awaits founder ruling" item for the doc-write gap.
